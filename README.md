# Shwetambara FOSS Labs

Open source tools, standalone packages and small apps.

Code here is built for individuals and small teams looking for straightforward solutions without extra bloat.

* **Packages:** Small, focused libraries for specific tasks so projects don't have to carry unnecessary boilerplate logic.
* **Apps:** Functional tools for everyday personal tasks or small workflows.

---

### Research

Some repositories include write-ups, reports or exploratory papers linked directly in the project. 

Areas of interest for future work include:
* Human-computer interaction (HCI)
* Cryptography
* Cybersecurity

### Contributing

All public code is open to use. Issues, bug reports and pull requests are welcome in individual repositories.
